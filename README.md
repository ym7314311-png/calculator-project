# 🧮 C++ Calculator Project

## 📌 Overview
This is a simple console-based calculator built using C++.  
It performs basic arithmetic operations and includes input validation.

---

## ⚙️ Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero (shows "Undefined")
- Detects invalid operators

---

## 🧠 Concepts Used
- Functions in C++
- Conditional statements (if-else)
- User input/output
- Basic error handling

---

## 💻 How it works
The user enters:
- First number
- Operator (+, -, *, /)
- Second number

The program then displays the result.

---

## 🚀 Example
Enter n1: 5  
Enter op: +  
Enter n2: 3  
Result = 8
